# NovaGame M1 First SwordMaster Domain Slice

## Objective

Select and implement exactly one concrete SwordMaster-backed domain capability as a game-owned vertical slice using the verified NovaGame M0.5 infrastructure.

M1 implements a SwordMaster-owned backend slice that happens to use concepts such as character attributes, items, and equipment. It does not establish those concepts as NovaGame domains. M1 collects evidence about reuse pressure but does not add a business abstraction or mechanism to NovaGame.

The complete capability is implemented in a separate SwordMaster backend. Even when M2 later finds reusable evidence, NovaGame may receive only a minimal mechanism; SwordMaster retains its equipment domain, rules, persistence extensions, APIs, administration, and client policy.
